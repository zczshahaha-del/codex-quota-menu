# 第一版需求

## 解决的问题

使用 Codex 时，希望不用打开设置页或输入命令，就能随时看到还剩多少额度、距离重置还有多久。

## 使用者

当前第一版给张成在自己的 Mac 上使用。

## 第一版必须具备

- 常驻 macOS 菜单栏右侧。
- 菜单栏文字使用 `剩余百分比·重置倒计时`，例如 `77%·6d`。
- 点击后只显示 Codex 主额度的周期、剩余百分比和准确重置时间。
- 弹层使用接近 macOS 控制中心的圆角玻璃外观。
- 启动时读取，之后每 5 分钟自动刷新，并支持手动刷新。
- 找不到 Codex、尚未登录或请求失败时显示可理解的错误。
- 不显示 Dock 图标，不保存账户凭据。

## 第一版明确不做

- 不放进左侧的应用菜单区域。
- 不支持 Windows 或 Linux。
- 不做 App Store 发布、自动更新和开机启动。
- 不消耗额度重置机会，不修改 Codex 账户数据。
- 默认界面不展示其他模型额度、更新时间或操作按钮。
