# 第一版需求

## 解决的问题

使用 Codex 时，希望不用打开设置页或输入命令，就能随时看到还剩多少额度、距离重置还有多久。

## 使用者

当前第一版给张成在自己的 Mac 上使用。

## 第一版必须具备

- 常驻 macOS 菜单栏右侧。
- 菜单栏文字使用 `剩余百分比·重置倒计时`，例如 `77%·6d`。
- 点击后显示 Codex 主额度的周期、剩余百分比、准确重置时间及今日 token 用量。
- 今日 token 用量统计本机 Codex 所有会话及归档会话，按本地自然日计算；展示合计、输入和输出，悬停可看准确计数及缓存输入。缓存是输入的子集，推理是输出的子集，不额外相加。
- 合计、输入、输出的简写不到 1 亿使用万，达到 1 亿使用亿，最多保留两位小数，去掉末尾多余的零。
- 用量每分钟及手动刷新时更新，后台增量读取，不阻塞菜单；读取失败不提示，无数据用 `--` 占位。跨天时不继续展示昨日数字。
- 用量重复记录不多算；目录和用量均未改变时复用缓存，新增、归档、删除、替换及跨天仍及时更新。后台错误日志有大小上限。
- 弹层使用接近 macOS 控制中心的圆角玻璃外观。
- 启动时读取，之后每 1 分钟自动刷新，并支持手动刷新。
- 卡片右上角提供可见的「⋯」入口，点击可刷新或退出，悬停显示操作提示。
- 找不到 Codex、尚未登录或请求失败时不显示警告、错误或异常状态点；没有历史额度时显示 `--%`。
- 读取失败或断线后安静保留上次额度，后台继续每分钟刷新，成功后更新数字。
- 初始化或读取超过 20 秒时结束等待，后续刷新能够重新连接；同一时间只发起一个额度读取请求。
- 优先显示主额度窗口；主窗口缺失时显示可用的备用窗口。
- 不显示 Dock 图标，不保存账户凭据。

## 第一版明确不做

- 不放进左侧的应用菜单区域。
- 不支持 Windows 或 Linux。
- 不统计其他设备、云端 Codex 任务或普通 ChatGPT 聊天的 token，不推算费用。
- 不做 App Store 发布、自动更新和开机启动。
- 不消耗额度重置机会，不修改 Codex 账户数据。
- 默认界面不展示其他模型额度或更新时间；刷新与退出收纳在「⋯」菜单内。
