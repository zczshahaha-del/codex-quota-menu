# 统计修复与冗余清理

问题跟踪：[Issue #11](https://github.com/zczshahaha-del/codex-quota-menu/issues/11)。本文保留本机验收记录；代码通过 PR 合并，GitHub Release 单独处理。

## 范围与验收

- 修复旧请求重复出现导致 token 从 330 多算为 550 的问题，覆盖配对记录和重复旧格式事件。
- 后台 stderr 仅保留最近 64 KiB，验证持续日志及中文截断仍能安全结束等待。
- 移除不用的连接状态、错误文字状态、额外额度列表与读取时间；保留失败后结束刷新、主/备用窗口和旧版返回格式兼容。
- 会话目录未改变时复用文件列表；没有新用量时复用汇总，不重复合并当天全部记录。新增、归档、删除、替换、跨天仍正确。
- 保持当前界面、万/亿单位、静默重试和一分钟刷新；执行相关测试及通用应用构建。

## 已确认原因

旧的结构化记录会覆盖累计统计基线；重复旧格式事件随后把已统计的用量再次记入。后台 stderr 持续追加但没有长度限制。此前去掉提示后仍保留无人使用的可观察状态；解析器也继续整理不会显示的其他模型额度。读取器虽按文件位置增量读，但每次仍完整枚举目录及重建汇总。
