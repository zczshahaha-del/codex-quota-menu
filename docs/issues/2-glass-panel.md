# Issue 2：精简为单额度玻璃面板

## 为什么做

第一版弹层展示了所有模型额度和操作按钮，信息偏多。日常查看只需要 Codex 主额度，并希望外观接近 macOS 控制中心的圆角玻璃卡片。

## 本次范围

- 默认只展示 Codex 主额度。
- 保留标题、套餐、连接状态、额度周期、剩余百分比、进度条和重置时间。
- macOS 26 使用原生 Liquid Glass，旧系统使用半透明材质兜底。
- 移除默认界面中的 Spark、更新时间、刷新和退出按钮。
- 通过右键菜单保留“立即刷新”和“退出”。

## 不做

- 不改变菜单栏中的 `76%·6d` 紧凑格式。
- 不改变额度接口和刷新周期。
- 不增加安装、开机启动或通知功能。

## 完成条件

- [x] 弹层默认只出现一个 Codex 额度卡片。
- [x] macOS 26 显示原生玻璃效果。
- [x] 错误和加载状态仍然可理解。
- [x] 单元测试、Release 构建和实际界面检查通过。

## 验证记录

- 3 个单元测试通过。
- Release 应用构建、签名和启动成功。
- 在真实菜单栏中确认弹层只展示 Codex 主额度，圆角玻璃、进度条和重置时间显示正常。
