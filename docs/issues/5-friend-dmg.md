# Issue 5：制作朋友安装版 DMG

## 目标

将当前只能本机使用的应用包整理成方便发给朋友的安装镜像。

## 本次范围

- 构建同时支持 Apple Silicon 和 Intel 的通用应用。
- 增加正式的应用图标。
- 制作包含应用、Applications 快捷入口和中文安装说明的 DMG。
- 对应用、ZIP 和 DMG 做结构与完整性检查。

## 当前限制

本机没有 Developer ID Application 证书，只有 Apple Development 证书。因此本次先提供临时签名的朋友测试版，无法提交 Apple 公证；朋友首次打开仍需手动确认。

## 完成条件

- [x] 应用二进制同时包含 `arm64` 和 `x86_64`。
- [x] Finder 能显示应用图标。
- [x] DMG 中包含应用、Applications 快捷入口和安装说明。
- [x] 单元测试、签名检查、DMG 挂载检查通过。

## 检查结果

- 3 个单元测试通过。
- 应用二进制确认为 `arm64 + x86_64` 通用格式。
- 临时签名验证通过，应用图标在 Finder 中显示正常。
- DMG 校验和有效，可正常挂载，并包含应用、Applications 快捷入口和安装说明。
- 实际打开 DMG 检查了安装窗口尺寸与图标位置。
