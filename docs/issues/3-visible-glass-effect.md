# Issue 3：玻璃效果不明显

## 现象

0.2.0 虽然调用了原生 `glassEffect`，实际弹层仍接近普通深色圆角面板，肉眼看不出控制中心卡片的透亮层次。

## 环境与重现

- macOS 26.6.2。
- 打开 `Codex 余量.app`，点击菜单栏额度。
- 弹层背景与卡片颜色过于接近，边缘和高光很弱。

## 原因

`MenuBarExtra` 自带不透明度较高的窗口背景。卡片在其上使用无色的默认玻璃材质时，采样到的背景近似纯色，因此虽有原生材质，视觉上仍像普通深色面板。

## 解决方法

- 将弹层宿主窗口改为透明，让玻璃材质能够采样窗口后的真实内容。
- 为玻璃卡片增加系统控制中心式的轻微亮色调、方向性高光边框和柔和阴影。
- 旧系统继续使用半透明系统材质，并保持同样的边缘层次。

## 完成条件

- [x] 卡片与窗口外框不再叠成两层深色矩形。
- [x] 卡片边缘、高光和背景透色肉眼可见。
- [x] 信息可读性不受影响。
- [x] 测试、构建和真实截图检查通过。

## 检查结果

- 3 个单元测试通过。
- macOS 26 Release 版本构建和启动成功。
- 真实菜单栏截图确认卡片已有明显灰色玻璃层、方向性亮边与背景分离感。
