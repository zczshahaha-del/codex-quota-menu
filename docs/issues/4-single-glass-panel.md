# Issue 4：弹层出现双重圆角框

## 现象

0.2.1 的卡片外面仍有 `MenuBarExtra` 自带的弹窗容器，形成明显的双重圆角框。整体显得厚重，和控制中心的单层玻璃控件不一致。

## 环境与重现

- macOS 26.6.2。
- 点击菜单栏中的额度文字。
- 能同时看到外层深色弹窗边框和内层灰色玻璃卡片边框。

## 原因

SwiftUI `MenuBarExtra` 的 `.window` 样式会固定创建系统弹窗表面。应用又在里面绘制了一层玻璃卡片，即使尝试把窗口背景改透明，系统容器仍然参与渲染。

## 解决方法

- 改用原生 `NSStatusItem` 管理菜单栏文字。
- 点击后显示自定义透明、无边框 `NSPanel`。
- 透明窗口中只绘制一个原生 Liquid Glass 卡片。
- 同时缩小宽度、内边距和段落间距。

## 完成条件

- [x] 弹层只剩一个圆角轮廓。
- [x] 窗口外部完全透明，不出现第二层底板。
- [x] 点击菜单栏可正常显示和关闭，额度仍会自动更新。
- [x] 测试、构建与真实截图检查通过。

## 检查结果

- 3 个单元测试通过。
- Release 应用构建并启动成功。
- 真实截图确认弹层只有单层玻璃轮廓，连续点击菜单栏可正常显示和关闭。
